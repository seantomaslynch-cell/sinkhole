## Long description

```
You drop into a collapsing sinkhole on a winch line. Deeper is worth more.
Your lamp is the only clock you have.

One input runs the whole game. Hold to pay out the line and sink. Let go and
the winch hauls you home. Treasure is picked up automatically as you fall — and
every single piece of it makes the climb back slower.

So the only question Sinkhole ever asks is the one that matters: do you take
one more, or do you start climbing? The lamp bar shows exactly what the trip
home will cost from where you are right now. Watch it close on you.

Push too deep and the dark takes the lot. Bank what you carry and buy a better
lamp, a stronger winch, a bigger satchel — then go deeper than you should have
gone last time.

FIVE DEPTHS AND THE DARK BELOW
Topsoil, Limestone, Crystal Vein, Sulphur Deep, Bone Cathedral — then The Deep,
which never ends. Gas pockets triple your lamp burn. Wall snags catch a line
swinging too wide. Rockfalls hit hardest on the way up.

A run takes under a minute. You will start another one.
```

## Controls

```
Touch:    Hold anywhere on the screen to descend. Release to climb.
Mouse:    Hold left button to descend. Release to climb.
Keyboard: Hold Space or Down Arrow to descend. Release to climb.
```

## Orientation

```
Portrait and landscape both fully supported. The game reads the live viewport
aspect and re-lays the shaft on every resize and rotation — no letterboxing and
no locked orientation.
```

## Age rating / content

```
Suitable for all ages. No violence, no gore, no horror imagery, no text chat,
no user-generated content, no external links, no account or login required.
Failure is losing the treasure you were carrying — there is no death, no
permadeath and no game-over screen.
```

## Monetization declared

```
Interstitial ads   — at run end, gated to roughly 90 seconds apart
Rewarded ads       — optional: relight the lamp after a failed run, or double a
                     successful haul. Both are entirely optional; the full game
                     is playable without ever watching one.
Advanced banners   — menu and result screens only, never during a run
In-app purchases   — none
```
